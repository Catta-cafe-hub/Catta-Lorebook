# Catta Lorebook

ส่วนเสริม Lorebook สำหรับ SillyTavern ของ Catta

## ติดตั้ง

ใช้ลิงก์นี้ในเมนูติดตั้งส่วนเสริมของ SillyTavern:

`https://github.com/Catta-cafe-hub/Catta-Lorebook`

## การใช้งาน

- ใช้บัญชี Catta เดียวกับส่วนเสริม Catta อื่น
- ค้นหา เลือกใช้ และอัปโหลด Lorebook ผ่านแผงส่วนเสริม
- 1 Lorebook = 1 สล็อต: Basic 10 / VIP 20 / VVIP 100
- เก็บเข้าคลังเพื่อคืน 1 สล็อตโดยไม่ลบถาวร
- เจ้าของสามารถลบ Lorebook ของตัวเองออกจากระบบแบบถาวรได้
- ตั้งงบ Lorebook ได้สูงสุด 25,000 โทเคน

## การยืนยันสมาชิกและข้อมูล (0.3.1)

- ตรวจสมาชิก Catta ที่ล็อกอินทุกครั้งที่เปิดหน้า และตรวจซ้ำทุก 120 วินาที
- เมื่อสิทธิ์ถูกเพิกถอน จะล็อก Cloud และล้างเนื้อหาที่เลือกอยู่ใน RAM
- ไม่เรียก saveWorldInfo() และไม่สร้าง World Info แบบไฟล์ถาวร แต่รายการชั่วคราวที่ใช้สร้าง Prompt อาจปรากฏใน Inspector
- เนื้อหา Lorebook ที่เลือกถูกส่งมายังเบราว์เซอร์เพื่อจับ Keywords; เจ้าของเครื่องยังดูผ่าน DevTools/Network ได้ ไม่ใช่ DRM
- สมาชิก Discord ที่ยืนยันตัวตนใช้หนังสือที่แชร์ได้ แต่การอัปโหลดต้องมี Basic/VIP/VVIP ตามโควต้า

## สิทธิ์เนื้อหา

เนื้อหาและงานเขียน Prompt ใน Lorebook เป็นผลงานและทรัพย์สินทางปัญญาของผู้สร้างแต่ละราย โปรดใช้งานตามสิทธิ์ที่ผู้สร้างกำหนด ห้ามคัดลอก ดัดแปลง เผยแพร่ หรือนำเนื้อหาไปใช้ต่อนอกสิทธิ์ที่ได้รับ
