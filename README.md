# Catta Lorebook

ส่วนเสริมคลัง Lorebook บน Cloud Catta สำหรับ SillyTavern 1.19.0 ขึ้นไป

รุ่น 0.4.3 ใช้ Catta Night และแสดงแท็บอัปโหลดเฉพาะเชฟที่มีแพ็กเกจ หรือ VVIP ใช้บัญชีและ Login Token ร่วมกับส่วนเสริม Catta เดิม ตรวจบัญชีตอนเปิดหน้า/เปลี่ยนบัญชีเท่านั้น ไม่มีรอบตรวจตามเวลาหรือการตรวจเมื่อสลับหน้าต่าง

## ติดตั้งหรืออัปเดต

ติดตั้งจาก `https://github.com/Catta-cafe-hub/Catta-Lorebook` ผ่านเมนู Extensions ของ SillyTavern หากติดตั้งแล้วให้อัปเดตส่วนเสริมและรีโหลดหน้าเว็บ

## เริ่มใช้งาน

1. เชื่อมบัญชีด้วย Discord User ID และ Login Token ของ Catta ใช้บัญชีร่วมกับส่วนเสริม Catta อื่นได้
2. เลือกแชทเดี่ยวของตัวละคร แล้วเลือกหนังสือจากแท็บ **ของฉัน** หรือ **ค้นหา**
3. ถ้าเป็นหนังสือล็อกรหัส ให้กรอกรหัสตัวเลข 6 หลักจากผู้สร้างก่อนเลือกใช้
4. เปิด **เชื่อมกับแชทนี้** แล้วกด **เริ่มใช้งาน** เพื่อตั้งค่าจำนวนข้อความที่สแกนและงบโทเคน
5. ส่งแชทผ่าน Chat Completion ตามปกติ

การเลือกหนังสือและการเชื่อมต่อแยกตามแชท อยู่ในหน่วยความจำของหน้าเว็บ รีโหลดแล้วเลือกหนังสือใหม่ได้จาก Cloud

## อัปโหลดและแชร์

อัปโหลดไฟล์ Lorebook / World Info JSON ที่ export จาก SillyTavern ขนาดไม่เกิน 2,000,000 bytes เลือกสิทธิ์ก่อนเผยแพร่:

| สิทธิ์ | ใครเลือกใช้ได้ |
| --- | --- |
| ส่วนตัวของฉัน | เจ้าของบัญชีเท่านั้น |
| แชร์ให้ทุกยศ | สมาชิก Discord Catta ที่เข้าสู่ระบบ รวมสมาชิกที่ไม่มียศแพ็กเกจ |
| เลือกยศ | เลือก Basic / VIP / VVIP ได้หลายยศ ตรวจตามแพ็กเกจปัจจุบันที่ยังไม่หมดอายุแบบตรงยศ |
| ล็อกรหัส 6 หลัก | สมาชิก Catta ที่เข้าสู่ระบบทุกยศ โดยต้องกรอกรหัสก่อนเลือกใช้ |

เลือก Basic อย่างเดียวจะไม่รวม VIP หรือ VVIP อัตโนมัติ ระบบใช้แพ็กเกจที่ยังมีสิทธิ์สูงสุดของสมาชิกเป็นยศปัจจุบัน

อัปโหลดได้เฉพาะเชฟที่มี Basic/VIP/VVIP ที่ยังใช้งานอยู่ หรือ VVIP ที่ยังใช้งานอยู่ ยศเชฟเป็นยศเสริม ไม่แทนแพ็กเกจ โควต้ายังคงตามแพ็กเกจ: เชฟ+Basic 10 / เชฟ+VIP 20 / VVIP 100 สล็อต โดย 1 Lorebook ใช้ 1 สล็อต

Basic/VIP ที่ไม่ใช่เชฟและสมาชิกทั่วไปจะไม่เห็นแท็บอัปโหลด แต่ยังเลือกใช้ Lorebook ตามสิทธิ์ที่ผู้สร้างกำหนดได้ หนังสือเดิมไม่ถูกลบเมื่อเสียสิทธิ์อัปโหลด หากยศเปลี่ยนระหว่างเปิดหน้า ให้รีโหลดเพื่ออัปเดตแท็บ ไม่ต้องสร้างบัญชีใหม่ API ยังบังคับสิทธิ์อัปโหลดทุกครั้ง

เจ้าของเปลี่ยนสิทธิ์หรือรหัสได้จากเมนู **••• → ตั้งค่าสิทธิ์การแชร์** การเปลี่ยนรหัสยกเลิกการปลดล็อกเดิม ผู้ใช้งานต้องรับรหัสใหม่จากผู้สร้าง เก็บเข้าคลังเพื่อคืนสล็อตได้โดยไม่ลบถาวร หรือเลือกคำสั่งลบถาวรพร้อมยืนยัน

## ความปลอดภัยและความเป็นส่วนตัว

- API ตรวจสมาชิกและสิทธิ์ฝั่งเซิร์ฟเวอร์ก่อนคืนเนื้อหาและก่อนสร้างข้อความแต่ละครั้ง
- รหัส 6 หลักถูกเก็บเป็นค่าแฮชพร้อม salt และความลับฝั่งเซิร์ฟเวอร์ มีการจำกัดจำนวนครั้งที่ลองรหัส
- การปลดล็อกผูกกับสมาชิก หนังสือ รอบสิทธิ์ และการล็อกอิน มีอายุ 15 นาที เก็บหลักฐานเฉพาะใน RAM ไม่บันทึก PIN หรือเนื้อหาใน localStorage
- ไม่มีการตรวจบัญชีตามเวลา หรือตรวจเพียงเพราะกลับมาโฟกัสหน้าต่าง หนังสือที่เลือกจะไม่ถูกล้างเพราะรอบตรวจเบื้องหลัง
- หากติดต่อเซิร์ฟเวอร์ไม่ได้ชั่วคราว ระบบเก็บหนังสือที่เลือกไว้ และหยุดคำขอสร้างข้อความที่ตรวจสิทธิ์ไม่ได้ ให้ลองใหม่เมื่อเชื่อมต่อได้ โดยไม่ส่งข้อความแบบขาด Lorebook
- ออกจากระบบหรือเปลี่ยนบัญชีจะล้างข้อมูลของบัญชีเดิม ถ้า API ยืนยันว่าล็อกอินหรือสิทธิ์หนังสือใช้ไม่ได้แล้ว จะหยุดใช้งานและล้างเนื้อหาที่เลือกเพื่อป้องกันการใช้ข้ามสิทธิ์ อายุปลดล็อก PIN ยังคง 15 นาทีตามเดิม
- ไม่ส่งประวัติแชทไป Cloud Catta เพื่ออัปโหลดหรือปลดล็อกหนังสือ เนื้อหาที่ถูกเลือกจะส่งไป AI ผ่านการเชื่อมต่อปกติของ ST
- ไม่สร้างไฟล์ native World Info ของหนังสือ Cloud แต่เจ้าของเครื่องยังตรวจข้อมูลใน DevTools/Network หรือคำขอ AI ได้ จึงไม่ใช่ DRM ที่รับประกันป้องกันการคัดลอก

เนื้อหา Lorebook เป็นผลงานของผู้สร้างแต่ละราย โปรดใช้งานตามสิทธิ์ที่ได้รับ ห้ามคัดลอก ดัดแปลง หรือเผยแพร่ต่อนอกสิทธิ์

รองรับแชทเดี่ยวและ Chat Completion; งบ Lorebook สูงสุด 25,000 โทเคน ฟีเจอร์ World Info บางประเภท เช่น Group Chat, recursive/timed entries และ vector ยังไม่รองรับ ระบบจะปฏิเสธไฟล์ที่ใช้รูปแบบที่ยังไม่รองรับ
